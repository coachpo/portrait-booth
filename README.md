# Portrait Booth

Portrait Booth 是一个用于制作个人肖像及常见护照、签证照片的 Web App 项目，计划支持上传或设备摄像头拍摄、脸部角度指导、模板裁剪、基础编辑、本地导出和短期跨设备取回。

## 当前状态

项目处于产品与技术规格阶段。仓库目前只有项目文档和代理指令，没有应用源代码、依赖清单、测试、构建配置或 CI。此处仅为派生摘要，项目状态以 [STATUS.md](STATUS.md) 为准。

## 安装和启动

当前没有需要安装的项目依赖，也没有可验证的应用启动命令。引入首个运行时工具链时，必须同时在本文件记录普通安装和启动方式，并在 [CONTRIBUTING.md](CONTRIBUTING.md) 记录开发、测试、检查与构建命令。
